First release: GLockdown for apps. `GlockdownStage` reads the stage GLockdown's agent writes for the app (off while the agent is not installed, full on a file it cannot read before any good read, the last good stage through any later fault), `strictest` combines it with the app's own sources, and `escalate` raises the app one rung over TLS pinned both ways. No dependencies.
